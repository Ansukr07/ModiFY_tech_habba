# Model card: Authenticity (auth-v2-tuned)

Dataset: IBM AML HI-Small, synthetic multi-agent transaction simulation. Algorithms tuned: XGBoost and Random Forest; selected candidate: xgboost. No SMOTE or other synthetic oversampling is used. RandomizedSearchCV performs 10 parameter samples per algorithm with three-fold training-only cross-validation using F1 scoring. The decision threshold is selected on validation data, and test metrics are in metrics_auth.json. Account-level stratified 70/15/15 split, seed 42. On the held-out accounts, suspicious prevalence is 1.49%; the majority-class accuracy baseline is 98.51%. XGBoost accuracy is 97.52% with 11.16% suspicious recall and 54.99% balanced accuracy; Random Forest accuracy is 98.49% with 4.25% suspicious recall and 52.08% balanced accuracy. These class-imbalance diagnostics are also in metrics_diagnostics.json. Raw scores are not calibrated. The model learns generator patterns and is not validated on Indian MSMEs or UPI.
